智能体编排框架

受控工具层

PDF解析、OCR、提取、检索、计算、校验、异常识别和报告生成。

 03 / PROMPT

Prompt 资产

系统、专项分析、评级、报告编辑、编排与证据问答 Prompt。

 04 / SKILL

财报分析 Skill

定义执行顺序、模型边界、失败处理、两页报告和审计要求。

 05 / MCP

stdio MCP 服务

提供状态、财报列表、受控分析和白名单产物读取工具。

 06 / AUDIT

数据与日志

结构化事实、公式输入、来源页码、manifest、JSONL事件和模型调用哈希。

浏览器能力边界

点击“打开本地分析台”会直接进入已经运行的分析服务，不再通过跨源请求预先检测。普通 HTML 受浏览器安全限制，不能直接执行本机 CMD；如果分析服务尚未运行，请先双击根目录的“启动本地分析台.cmd”。进入分析台后，系统会先让用户在“示例研报”和“本地研报”之间选择，再显示对应内容。

本地启动

双击根目录的 启动本地分析台.cmd，等待浏览器自动打开；首次运行会创建环境并安装依赖，使用期间请保持 CMD 窗口开启。
