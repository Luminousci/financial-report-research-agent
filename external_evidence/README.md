# 受控外部证据目录

将行业数据、新闻摘要、政策材料或公司公告的结构化摘录放在本目录。系统只读取 `.json`、`.csv`、`.md` 和 `.txt`，并按公司名称或证券代码匹配当前财报。

推荐使用JSON：

```json
{
  "title": "材料标题",
  "as_of_date": "2026-09-27",
  "tags": ["行业", "政策"],
  "content": "包含公司全称或证券代码的材料摘要。"
}
```

每个文件会登记绝对路径、SHA256和内容摘要。原始文件不会被修改。请只放入允许用于比赛的数据，并在 `THIRD_PARTY.md` 中登记来源、日期、许可证或使用授权。
