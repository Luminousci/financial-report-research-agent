# 财报文件放置与命名规范

本目录属于智能体的受控数据环境。启动分析台后，系统会递归读取本目录中的 PDF。

## 推荐目录

- `示例/`：随提交物提供的少量演示财报。
- `本地导入/`：网页“从本地文件夹导入财报”功能自动复制并规范命名的文件。
- 可自行创建公司或年份子目录；系统会递归发现其中的 PDF。

## 文件名规范

统一格式：

```text
股票代码_公司简称_报告期_报告类型.pdf
```

报告期使用以下形式：

- 年报：`2025FY`
- 半年报：`2025H1` 或 `2025H2`
- 季报：`2025Q1`、`2025Q2`、`2025Q3` 或 `2025Q4`

规范示例：

```text
600519_贵州茅台_2025FY_年度报告.pdf
601398_工商银行_2025H1_半年度报告.pdf
000651_格力电器_2026Q1_第一季度报告.pdf
```

不要在文件名中使用 `<>:"/\|?*`，也不要使用“最终版”“新版”“报告1”等无法区分公司和期间的名称。

## 放入环境的两种方式

1. 推荐：在分析台选择“从本地选择文件”后选择PDF。系统会读取前8页，自动回填股票代码、公司简称、报告期和报告类型，并显示置信度与来源页码。核对或修改字段后点击“确认并使用”，系统会校验 PDF 并复制到 `本地导入/`；导入接口还会对缺失字段执行一次服务端识别兜底。扫描型PDF无可用正文时会提示需要OCR，此时应人工确认字段。若只需演示，也可直接选择“选择示例”。
2. 手动：将已经按上述规则命名的 PDF 复制到本目录或其子目录，刷新分析台后即可选择。

网页导入不会修改原始文件；单份 PDF 上限为 80 MB。同名文件不会被覆盖，而会保存为带“副本”序号的新文件。
