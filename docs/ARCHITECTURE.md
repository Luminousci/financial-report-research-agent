# 系统架构

## 设计原则

1. 大模型理解语义，程序负责数值、单位、期间和勾稽。
2. 每个字段先成为带来源的事实，之后才能进入计算和分析。
3. 原生文本优先，OCR是页面级回退，不是全量默认路径。
4. 工作流节点固定，模型不拥有任意文件或任意网络访问权限。
5. 所有外部调用均保存请求哈希、响应哈希、模型版本和耗时。

## 模块

- `document.py`：文件身份、报告类型、行业和会计准则分类。
- `pdf_parser.py`：PDF文本质量检测、候选页面和表格抽取。
- `ocr.py`：AI Studio及百度智能云OCR适配。
- `mcp_server.py`：受控stdio MCP工具服务，不提供任意文件或命令访问。
- `extractor.py`：科目映射、单位和期间标准化、证据定位。
- `business_update.py`：从短篇业务更新公告提取同比区间指标，并识别渠道与区域增速分化。
- `retrieval.py`：按业绩驱动、现金流、非经常性损益、会计口径和风险主题检索叙事证据。
- `calculations.py`：确定性财务计算。
- `health.py`：按行业配置执行透明健康评分并报告覆盖率；对缺少完整三表的经营快报返回“不适用”而非负面评级。
- `validation.py`：冲突、缺失、增长率复算和勾稽检查。
- `anomaly.py`：行业适用的异常规则。
- `deepseek.py`：按任务裁剪上下文，编排5个专项Agent并行分析，再串行执行评级Agent与报告编辑Agent；每个Agent独立限流、缓存、校验和回退。
- `chat.py`：报告级多轮问答、全文与结构化证据混合检索、会话持久化和纯检索回退。
- `report_compact.py`：最多两页的本地可视化研报及同主题证据问答抽屉；页面不展示原始来源附录，但证据仍保存在结构化产物与审计日志中。
- `report.py`：兼容入口，委托给紧凑研报渲染器。
- `webapp.py`：同源报告、后台分析任务、进度轮询、`/api/chat`和会话历史接口，并继承Web Basic Auth边界。长耗时分析不占用Cloudflare前台请求连接。
- `audit.py`：JSONL过程日志。
- `pipeline.py`：状态固定的任务编排。
- `timeline.py`：多期报告合并、累计值拆分、单季度与环比计算。

## 外部调用审计

AI Studio/百度OCR调用将输入图像SHA256、请求哈希、响应哈希、鉴权方式、耗时、
状态和识别字符数写入`ocr_metadata.json`及manifest。DeepSeek每个Agent调用都将角色、
模型、Prompt版本、请求哈希、响应哈希、响应ID、Token用量、耗时、缓存与成功/失败状态
写入`llm_metadata.json`，各Agent结构化结果另存`agent_outputs.json`；聚合状态写入manifest。
任何记录都不包含API Key。

## DeepSeek编排

1. 业绩变动、非经常性损益、会计口径、利润现金流背离、其他风险5个专项Agent并行执行。
2. 评级Agent只消费程序评分和专项结论，不重新计算财务指标。
3. 报告编辑Agent将结果压缩为两页研报字段，不追加无法定位证据的新事实。
4. 每个Agent采用独立Token上限和JSON解析；单个调用失败不会抹去已完成的确定性结果。
5. 模型输出只属于解释层，事实、同比、比率和评分始终由程序层生成。

报告问答将每一轮问题、检索证据、引用页码、回答、Prompt版本、模型元数据和耗时写入
`chat/<session_id>.jsonl`，并在该运行的`events.jsonl`追加哈希化工具事件。会话ID绑定运行目录，
路径经过输出根目录边界检查；离线或模型失败时只返回受控检索证据。

## 信任边界

PDF内容、OCR结果和模型输出均是不可信输入。程序不会执行这些内容中的指令。所有数值进入计算前必须通过类型、单位、期间和来源检查。密钥只从本地环境变量读取。
