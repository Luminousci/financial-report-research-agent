# 财报分析技能

## 目标

从上市公司定期报告中形成可追溯的结构化数据、程序计算、异常信号和分析报告。

## 执行顺序

1. 登记文件哈希、公司、报告期和文档类型。
2. 优先读取原生文本和表格；仅对低质量页面调用OCR。
3. 提取时同时保存原始字段、数值、单位、期间、合并口径和页码。
   - 若文档为 `business_update`，改用经营快报提取器，保留同比增速的上下限与OCR原文，不取中点。
4. 所有同比、单季度还原、现金含量和勾稽关系由程序计算。
5. 规则只负责发现候选异常；语义模型不得更改基础数值。
6. 并行运行业绩变动、非经常性损益、会计口径、利润现金流背离和其他风险5个专项Agent；每个Agent只接收其任务所需的事实、程序计算、规则结果与证据片段。
7. 评级Agent只汇总程序评分和专项结论；报告编辑Agent只做压缩、排序和边界表达，不自行新增数值或事实。
8. 生成最多两页的可视化研报；页面可隐藏来源附录，但必须在JSON与日志中保留页码、原文、公式、请求哈希和执行轨迹。
9. 报告生成后再次检查每个数字和重要结论是否能回溯到证据。

## 失败处理

- 文档不是完整财务报告时，明确标记材料范围，提取可核验的经营区间指标，但不补造缺失报表，不执行完整财报健康评分。
- OCR或模型不可用时，保留可复现的原生解析结果并标记待补步骤。
- 同一字段存在冲突时保留所有候选值，生成复核事项。
- 口径、期间或单位不明确时不得参与计算。
